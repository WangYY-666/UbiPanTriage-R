## 方法说明 Method

### 四维评分系统 Four-dimensional scoring

对输入的基因（或基因集），在所选癌种中计算 0–1 的四维评分：

1. **泛素维度 Ubiquitin**（各癌种恒定）
   基于 IUCCD2.0 分类的功能层级分：E3 连接酶 = 1.00、DUB = 0.90、
   E2 = 0.80、E1 = 0.75、ULD = 0.70、UBD = 0.65、其他泛素相关基因 = 0.60。
   表格/图中以全称展示（如 Ubiquitin ligase (E3)）。

2. **基础维度 Basic**（默认四项等权，可调）
   - 表达分 Expression：肿瘤中该基因表达水平的预计算分（0–1）
   - 差异分 Diff：肿瘤 vs 正常的差异分析（limma/edgeR/DESeq2/配对）得分
   - 生存分 Survival：单因素 Cox（OS）得分，显著基因按 |logHR| 排名（0.5–1），不显著为 0
   - ROC 分 ROC：生存 timeROC 与肿瘤 vs 正常诊断 AUC 的得分
   四项的相对权重可在"更多设置"中调整（0–1、一位小数、自动归一化，设 0 即剔除）。

3. **免疫维度 Immune**
   基因表达与免疫浸润特征（TIMER 默认；CIBERSORT / MCPcounter / ssGSEA / xCell 可切换）
   的 |Spearman 相关系数| 加权均值；所选方法内的各免疫细胞默认等权、可单独调权。
   五种方法本身内部等权——即每个方法内所有细胞类型默认等权。
   缺少所选方法浸润数据的癌种（如 LAML 无 TIMER）自动回退到其预计算的首个可用方法。

4. **代谢维度 Metabolic**
   基因表达与 7 条 GSVA 代谢途径（氨基酸 / 糖 / 能量 / 脂质 / 核苷酸 / TCA 循环 /
   维生素辅因子）的 |Spearman 相关系数| 加权均值，各途径默认等权、可单独调权。

### 综合评分 Combination

- 将所选维度（泛素 / 基础 / 免疫 / 代谢，可任选）按权重做加权平均；
  默认等权（1:1:1:1），使用者可在 0.1–1.0（一位小数、总和必须为 1）内修改。
- 跨癌种汇总：默认等权平均，可切换为按样本量加权。
- 排名 Rank：在每个癌种内、以全部泛素基因为背景（universe）逐维排名（得分越高排名越靠前）。
- 百分位 Pct：该基因在相同癌种组合下、全部泛素基因中的综合分百分位（1 为最佳）。

### 缺失数据处理 Missing data

无正常组织或差异数据的癌种（ACC、DLBC、LAML、LGG、MESO、OV、TGCT、UCS、UVM）：
基础分在可用子项上重归一化，避免因缺失而系统性偏低；涉及跨癌种比较时以 * 标注并谨慎解读。
选中这类癌种时界面会弹窗/顶部提示，使用说明（页面 5）也有说明。

### 数据来源 Data

- 表达：TCGA 33 癌种全基因 count / TPM / FPKM（整数编码存储，查询时解码）
- 差异：肿瘤 vs 正常（limma / edgeR / DESeq2 / 配对，多方法整合）
- 免疫浸润：TIMER、CIBERSORT、MCPcounter、ssGSEA、xCell
- 代谢：7 条代谢途径 GSVA 评分
- 泛素注释：IUCCD2.0 ubiquitin genes（并集 1553 个泛素相关基因）
